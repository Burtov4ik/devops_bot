# Telegram бот for PT_START
## Описание 
Этот Telegram-бот позволяет управлять удаленным сервером через SSH, выполняя команды для мониторинга системы, а также взаимодействует с PostgreSQL для поиска, сохранения и извлечения телефонных номеров и email-адресов. Бот также предоставляет функции для проверки сложности пароля и логирует все действия в файл.
